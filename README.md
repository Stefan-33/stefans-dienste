# Dienstplan

Stefans Dienstzeiten (Spalte Straub, Dienstplan Zentrale) zum Anschauen – für Sabrina.

- **Web-App:** https://stefan-33.github.io/stefans-dienste/ (iPhone/Android: „Zum Startbildschirm hinzufügen“)
- **Android-App:** https://github.com/Stefan-33/stefans-dienste/releases/latest/download/Dienstplan.apk

Der Plan liegt in `www/plan.json`. App und Web-App laden ihn bei jedem Öffnen neu –
eine Planänderung braucht keinen neuen App-Build.
